ActNow | Volunteer Management Platform
[Month Year] – [Month Year]

ActNow is a full-stack volunteer management platform designed to bridge the gap between NGOs and volunteers. The platform empowers NGOs to create and manage volunteering events while enabling volunteers to discover, register for, and participate in causes they care about — all in one seamless experience.

🔧 My Contribution
I worked on the [Backend / Frontend / Full-Stack] of this project, building [brief personal contribution — e.g., "the RESTful API and database layer" or "the responsive React UI and state management"].

🚀 Key Features
• Multi-role system supporting Volunteers, NGOs, and Administrators
• JWT-based secure authentication with admin approval workflow
• Event creation, discovery (search/filter by location, skills, date), registration, and attendance tracking
• Automated event status transitions (Upcoming → Ongoing → Completed) via scheduled cron jobs
• Real-time web push notifications, automated email alerts (Nodemailer), and SMS notifications (Twilio)
• Auto-generated PDF certificates for volunteers upon event completion
• Digital event passes and donation payment receipts
• Razorpay payment gateway integration for donations
• AI-powered chatbot assistant using Google Gemini
• File upload support for ID verification and event images
• Real-time activity tracking and logging
